# 方向策略账户隔离方案（阶段0）

> 决策（用户拍板）：**子账户 + 同进程**。影子期零交易权限；执行期子账户 + 独立 API key + 代码级边界。

## 1. 为什么必须隔离

方向策略与中性网格不能共用同一账户/同一市场：
- 持仓归属无法判断（策略平掉网格的仓）；
- 止损数量互相覆盖；
- PnL 与风险统计混账；
- 重启恢复无法判定订单所有者。

## 2. HL 子账户与 API key（用户侧操作）

1. **创建子账户**：Hyperliquid 主账户 → 子账户管理 → 新建（独立地址）。
2. **入金**：把实验资金（首期极小，如 $200）划入子账户。
3. **授权 agent wallet**：在官方界面为子账户授权 agent 私钥（**可交易、不可提现**），保存私钥。
4. **配置**（`.env`，与现有 HL 实例（io dex）键位隔离）：
   ```
   HL_DIR_MODE=paper            # 影子期无需；执行期 live
   HL_DIR_ACCOUNT_ADDRESS=0x…   # 子账户地址
   HL_DIR_AGENT_PRIVATE_KEY_FILE=/root/.secrets/hl-dir-agent.key   # 或 HL_DIR_AGENT_PRIVATE_KEY
   HL_DIR_DEX=                  # 空 = 核心市场（BTC 永续在核心）
   HL_DIR_FEE_RATE=0.00045
   HL_DIR_PROXY=                # 缺省回落 GLOBAL_PROXY
   ```
5. **资金上限纪律**：子账户只放实验资金；agent key 只交易不提现。

## 3. 同进程隔离设计（代码级边界）

| 维度 | 设计 |
|---|---|
| 进程 | 与主力 6 所同进程（用户拍板省运维）；方向策略异常**一律内部降级**（告警/PAUSED），不允许抛出主进程 |
| 适配器实例 | 独立 HL adapter 实例（`HL_DIR_*` 配置块），与现有 HL（io dex）实例互不共享状态 |
| 状态持久化 | 独立键（`dir`）与独立影子数据文件；不触碰 `.state.json` 既有键 |
| 账户 | 子账户 + 独立 agent key（资金/持仓/订单归属清晰） |
| 风控 | RiskEngine 只作用于方向策略实例；不读/不写主力所风险状态 |
| 影子期 | **零交易密钥**（纯公共行情），任何代码路径不含下单调用——由安全检查（任务 4.1）与测试锁定 |

## 4. 同进程 vs 独立进程（记录决策依据）

- **选同进程**：省一套 systemd/端口/仪表盘；影子期零风险；主力所已有看门狗/续跑保护。
- **接受的风险**：方向策略代码缺陷可能影响主进程（缓解：模块边界 + 异常降级 + 执行期前代码评审）；进程级崩溃不隔离（缓解：主力所续跑机制兜底）。
- **触发升级独立进程的条件**：执行期出现任何一次方向策略导致主进程异常/重启 → 立即拆分为独立进程（8088）。
